# java-racingcar-precourse

## 기능 목록

### 자동차 이름 입력

- 사용자로부터 경주할 자동차 이름을 입력받는다
  - 자동차 이름은 쉼표(,)를 기준으로 구분
  - 예외) 이름의 길이가 5자를 초과하는 경우 예외처리
  - 예외) 이름의 길이가 0인 경우(비어있는 상태) 예외처리
  - 예외) 이름에 공백이 포함된 경우 예외처리
  - 예외) 입력한 이름의 개수가 2개 미만이면 예외처리
  - 예외) 중복된 이름이 존재하면 예외처리
  - 예외가 발생한 경우 프로그램을 종료

### 시도 횟수 입력

- 사용자로부터 이동을 시도할 횟수를 입력받는다
  - 예외) 시도 횟수가 1 미만이면 예외처리
  - 예외) 시도 횟수가 숫자가 아니면 예외처리
  - 예외가 발생한 경우 프로그램을 종료

### 경주 진행

- 시도 횟수만큼 모든 자동차들을 전진한다
- 매 턴마다 자동차를 전진할 것인지 결정한다
  - 0에서 9 사이에서 무작위 값을 구한 후 4 이상일 경우 전진
- 경주 중인 모든 자동차들의 이름과 위치를 출력한다

### 경주 완료

- 경주가 끝나면 우승자 이름을 출력한다
  - 여러 명일 경우 쉼표를 이용하여 구분
